# ALO Education — Super Admin Guide

## Accessing Super Admin
1. Navigate to the application
2. Click "Employee Portal" in the navbar
3. Login with Super Admin credentials
4. You will be redirected to the Super Admin Control Center

## Super Admin Control Center
The master dashboard with 6 tabs:

### System Overview
- 12 system-wide metrics (leads, students, applications, revenue, employees, AI agents)
- System health cards (database, API, AI, cache)
- Recent audit logs (10 latest)
- Pending approvals

### Employee Control
- Employee count by designation, department, office
- Profile status breakdown
- Quick employee table
- Manage Employees → Employee Management
- Access Control → Access Control Center

### Branch Control
- Branch cards with employee/student/lead/revenue counts
- Performance comparison

### Country Control
- Country cards with university/course/scholarship/student counts
- Performance charts

### AI Command
- AI agent stats (1060 agents, 53 departments)
- Department grid
- Open AI Command Center → Enterprise AI (100 depts, DCC)

### System Settings
- General, Email, WhatsApp, SMS, Security, Backup settings
- Feature flags (12 toggles)
- View Audit Logs

## Enterprise AI Command Center
- 100 departments with DCC certification metrics
- 2,000 AI employees (20 per department)
- 10,000 skills, 50,000 prompt templates
- 500+ constitutional rules, 500+ SOPs
- 20 enterprise engines (Knowledge Graph, RAG, Memory, Planning, etc.)
- DCC certification check (9 criteria, 62/100 certified)

## Permission Matrix
- 57 permissions across 8 modules
- Tick-box UI for each role
- Backend enforcement via access-control.ts

## Course Management
- 218 courses across 92 universities
- CRUD with 6-tab form
- CSV import with validation

## Omnichannel Communication Center
- 8 connected accounts (WhatsApp, Facebook, Instagram, Gmail, SMS, Call Center)
- Unified timeline (all channels merged)
- AI document classification (27 types)
- Notification engine (5 channels)
- Consent management
