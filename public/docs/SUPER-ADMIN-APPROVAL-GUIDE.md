# Super Admin Approval Queue User Guide

## Field-Level Change Management
Super Admin reviews proposed AI or CSV import changes at `/admin/change-approval`.

## Available Actions
- **Approve & Publish:** Publishes proposed change directly into production and updates the data version.
- **Reject:** Declines proposed change with an optional audit note.
- **Edit & Approve:** Allows Super Admin to modify the proposed value before publishing.
- **Rollback:** Restores a previously approved change back to its former state.
