# ALO Education — Web + CRM Complete System

## Overview
ALO Education is a complete study-abroad operating system built with Next.js 16, TypeScript, Prisma, and Tailwind CSS 4. It includes a public website, student portal, partner portal, counselor portal, employee dashboards, CRM, AI tools, and enterprise HR management.

## Tech Stack
- **Framework**: Next.js 16 with App Router
- **Language**: TypeScript 5
- **Database**: Prisma ORM (SQLite for dev, PostgreSQL for production)
- **Styling**: Tailwind CSS 4 with shadcn/ui
- **AI**: z-ai-web-dev-sdk (LLM, VLM, TTS, ASR, Image Generation)
- **Auth**: NextAuth.js v4 with bcrypt password hashing
- **State**: Zustand, TanStack Query

## Quick Start
```bash
bun install
bun run db:push
bun run db:seed
bun run dev
```
